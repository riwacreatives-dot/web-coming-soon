## ✦ Overview

RIWA CREATIVES is an independent commercial ad art studio and growth laboratory engineered for high-ticket DTC, hospitality, and breakout luxury brands. Built with an uncompromising focus on aesthetic typography, fluid 3D WebGL dynamics, sub-0.8s load times, and founder-led performance discipline.

---

## ✦ Core Disciplines & Architecture

- **Commercial Poster Art**: Provocative, scroll-stopping ad direction and tactile street poster aesthetics.
- **Fluid 3D WebGL Dynamics**: Three.js liquid artwork canvases and custom GLSL visualizers.
- **High-Velocity Headless Web**: Sub-0.8s LCP page speeds, zero layout shift, Lenis smooth scrolling.
- **Predatory Performance Media**: Meta Advantage+, Google P-Max, and algorithmic bid rules scaling to 8-figure run rates.
- **Zero React Mouse Lag**: Pure Framer Motion `MotionValue` elastic physics running outside React re-render loops.
- **Fluid Multi-Theme System**: Dark and Light themes with kinetic circular spotlight text hover inversion.

## ✦ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + CSS Custom Variable Tokens
- **Motion & Physics**: [Framer Motion](https://www.framer.com/motion/) + [Lenis](https://lenis.darkroom.engineering/)

- **Icons**: [Lucide React](https://lucide.dev/)

## ✦ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/riwacreatives/WebSite-Riwa-Main-.git

# Navigate to project directory
cd WebSite-Riwa-Main-

# Install dependencies
npm install
```

### Development

```bash
# Start Vite development server
npm run dev
```

The application will be live at `http://localhost:3000`.

### Production Build

```bash
# Type check and compile optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
